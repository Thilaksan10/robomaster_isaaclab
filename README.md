# Robomaster Isaac Lab

This repository contains the implementation used for the training and evaluation
of reinforcement-learning-based motion controllers for a Mecanum-wheeled robot.

## Documentation

- [Isaac Lab Setup](docs/ISAACLAB_SETUP.md)  
  Instructions for setting up the remote Docker/Isaac Lab environment.

- [Robomaster Experiment Reproduction](docs/ROBOMASTER_REPRODUCTION.md)  
  Instructions for adding the robot assets, training the policies, generating
  evaluation trajectories, running the benchmarks, and reproducing the results.
